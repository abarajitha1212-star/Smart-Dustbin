# Components – Smart Dustbin

The following list is based on the project poster and the project team's confirmation.

| Component | Intended / general purpose in the concept |
|---|---|
| Arduino Uno | Main controller in the proposed electronic arrangement |
| Ultrasonic Sensor (HC-SR04) | Distance or bin-level sensing concept |
| IR Sensor / Limit Switch | Detection input / lid or status sensing concept |
| Moisture Sensor | Intended to help distinguish wet and dry waste |
| Servo Motor | Proposed movement of a lid or waste-direction mechanism |
| Buzzer | Audio alert |
| LED Indicator | Visual status indication |
| 5V Power Supply (Adapter / Battery) | Power for the electronic components |
| Connecting Wires | Electrical connections |
| Dustbin with lid / two compartments | Physical model with WET and DRY sections |

**Accuracy note:** The poster explicitly lists Arduino Uno, HC-SR04, IR Sensor / Limit Switch, Servo Motor, Buzzer, LED Indicator, 5V supply, connecting wires and dustbin with lid. The team separately confirmed that a moisture sensor is also present. The exact sensor models and circuit connections are not documented here.
