# Working Principle and Model Scope

## Intended concept

The Smart Dustbin model demonstrates the idea of separating waste into two compartments labelled WET and DRY.

1. Waste is placed at the top/input section.
2. The moisture sensor is intended to provide an indication used to distinguish wet and dry waste.
3. The proposed controller arrangement uses the sensor input to choose a compartment.
4. A servo motor is proposed to operate a lid or guide mechanism.
5. Other listed sensors and indicators can support presence/status detection and alerts.

## Important clarification

This is a college **dummy / demonstration model**. The description above explains the intended design, not a verified working sequence. The project information supplied does not include confirmed wiring, Arduino pin numbers, source code, moisture thresholds, calibration results or test data. These have therefore not been invented.

## Limitations

- Sorting performance has not been measured.
- Different types of waste may require calibration and additional handling design.
- The prototype should not be represented as a fully automatic commercial product.
- A working implementation would need a verified circuit, firmware and repeatable tests.
