## 1. Introduction

Waste segregation is an important step in maintaining a clean and healthy environment. The Smart Dustbin project presents a simple model with two separate compartments labelled WET and DRY. The aim is to demonstrate the concept of identifying waste and directing it to the suitable compartment.

## 2. Objectives

- To demonstrate the concept of wet and dry waste segregation.
- To create awareness about separating waste at the point of disposal.
- To present a simple physical model with two compartments.
- To explain the proposed use of sensors, a controller and a servo mechanism.

## 3. Project Description

The model contains two compartments, one for wet waste and another for dry waste. The project poster describes an electronic arrangement using an Arduino Uno, sensors, a servo motor, LEDs and a buzzer. The team has confirmed that a moisture sensor is also included.

## 4. Components

1. Arduino Uno
2. Ultrasonic Sensor (HC-SR04)
3. IR Sensor / Limit Switch
4. Moisture Sensor
5. Servo Motor
6. Buzzer
7. LED Indicator
8. 5V Power Supply (Adapter / Battery)
9. Connecting Wires
10. Dustbin with lid / two-compartment model

## 5. Proposed Working Principle

Waste is placed at the top/input area of the model. The moisture sensor is intended to help identify whether the waste is wet or dry. In the proposed design, the controller selects the corresponding compartment and a servo mechanism guides or opens the route. The ultrasonic sensor and IR sensor / limit switch are listed for detection or status-related functions. LEDs and a buzzer are listed as indicators.

**This is the intended concept, not a claim that all automatic functions have been tested.** The project is a dummy / demonstration model.

## 6. Applications

The concept may be useful for explaining waste segregation in homes, offices, schools, colleges, hospitals and public places. These are potential application areas, not confirmed installations.

## 7. Advantages

- Demonstrates the importance of wet and dry waste separation.
- Helps create environmental awareness.
- Provides a simple platform for learning about sensors and automation concepts.
- Uses a two-compartment layout that is easy to understand.

## 8. Limitations

- The model is a dummy / educational demonstration.
- Sorting accuracy and continuous operation have not been verified.
- Detailed circuit connections, Arduino pin mapping, source code and test results were not supplied.
- A real-world system would require calibration, testing and a reliable mechanical design.

## 9. Conclusion

The Smart Dustbin project demonstrates the concept of separating wet and dry waste using a two-compartment model. It introduces how sensors, a controller, a servo motor and indicators could be used in an automated waste-segregation system. The current work is presented as a college demonstration model and can be developed further through verified hardware integration and testing.
